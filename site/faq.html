Questions

Straight answers, including what Pitoo can't do yet.

The basics

Is Pitoo free?

Yes. It's open source under the MIT license, with no account and no paid plan. If you use a cloud AI provider, that provider charges you for what you use.

Do I need AI to use it?

No. The editor, terminal, Git, debugger and code help all work with no model and no key. Press one shortcut and the agent is gone.

Does it really work with no internet?

Yes. The editor and its built-in code help need no connection, and neither does a local model once it's downloaded. Pushing code, the extension store and cloud AI do need one.

Which systems does it run on?

Mac with Apple Silicon, and 64-bit Windows and Linux. Windows and Linux have run on automated test machines, but haven't been used much on real desktops yet.

Why does my system warn me when I install it?

The app isn't signed or notarized yet, because that costs money and setup for a new project. The code is public, and you can build it yourself. See Install.

Why is it called Pitoo?

It's named after the maker's fluffy orange cat, who has green eyes and watches the screen. That's the cat in the logo.

Wasn't this called Anvil?

Yes, until version 0.4.0. Several other developer tools use that name, so it was hard to find. Updating brings your settings and chats across. API keys need entering once more, because they're encrypted to the old app name.

Compared to VS Code

Does it replace VS Code?

For many people working in TypeScript, Angular or Python, it can cover the daily work. VS Code is far more mature and has a huge extension library, so if you depend on specific extensions, keep it.

Do VS Code extensions run?

Themes and snippets do. Extensions that are programs don't, because they're written for VS Code's internal engine. Editors that run them, like Kiro and Trae, are built from VS Code's own source code. Pitoo isn't. The Extensions panel labels what each one can do.

Can I bring my setup across?

One button imports your settings, snippets and color themes. Pitoo also reads .vscode/settings.json, tasks.json, launch.json and .code-workspace files.

Which languages have full code help?

TypeScript, JavaScript, Python and Angular templates. HTML, CSS and JSON get some completion, and other languages get syntax colors.

Can I change the keyboard shortcuts?

Not yet. The main ones match VS Code.

AI and privacy

Can I use my Claude Pro or Max subscription in the chat?

Not in Pitoo's own chat. Anthropic's rules don't let other apps offer Claude login or route requests through subscription plans, so the chat uses a local model or an API key. You can run the official Claude Code in Pitoo's terminal with your subscription: the Claude Code button opens it, and it handles its own sign-in.

Can the agent read my passwords and keys?

By default it can't open, list or search .env files, private keys and similar files, and you can add more in .pitooignore. A command you approve runs with your permissions and could read them, so check commands before you allow them.

Does my code leave my computer?

Not with no AI or a local model. With Anthropic, OpenAI or a remote server, the code the agent reads and your messages go to that provider. The chat box always tells you which one you're using. Pitoo has no telemetry.

How good is a local model?

On a 16 GB MacBook, a 6 GB model is good for single files, small features and tests while you review the work. In one test it wrote about 24 tokens per second and finished a feature across 11 files in about 10 minutes, though earlier versions of that test failed. It can't reliably build a whole project alone.

Is it safe to let the agent run commands?

Commands ask first by default. Once you approve one, it runs with your full user permissions, and Pitoo can't undo what it changes. Leave Auto-run off unless you trust the project.

Can I undo what the agent did?

Yes. Keep or undo each block, each file, or everything, and Undo this step restores every file from a step. This covers file edits, not what a command did.

Why does Pitoo ask before running ESLint and Prettier?

Their config files are code from the project. Opening a project you don't trust shouldn't run its code, so you allow it once per project.

What it can't do yet

What's missing?

Program extensions, remote development, Live Share, built-in Docker tools, deep code help for other languages, and more than two side-by-side splits.

How well tested is it?

A test suite runs on Mac, Windows and Linux machines. It's a new project, though, and some parts haven't been tried in real use, including the Anthropic and OpenAI connections with real keys, pull requests, the Chrome debugger and updating to a new version. Please report what you find.

Can I help?

Yes. The code is on GitHub, and bug reports from real use help most.
