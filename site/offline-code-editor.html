A code editor that works offline

Pitoo is a free, open source desktop editor. Install it once, and it keeps working with the Wi-Fi off, with no account and no key.

What works with no internet

  • The editor, tabs, splits, search and the terminal
  • Errors, completion, go to definition and rename for TypeScript, JavaScript, Python and Angular
  • Your project's own ESLint and Prettier, once you trust the project
  • Git, apart from pushing and pulling, plus the debugger for JavaScript, TypeScript and Python
  • An AI agent, if you run a local model through MLX, Ollama or LM Studio

What needs the internet

  • Downloading the app and any model
  • Git push, pull and pull requests
  • Installing extensions from Open VSX
  • Cloud AI providers, if you choose one
  • Checking for updates

Who it's for

People who code on planes or unreliable connections, and people who'd rather keep their code on their own computer. There's no telemetry in the app.
