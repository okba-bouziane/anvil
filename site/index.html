Models make mistakes. Anvil makes them cheap to undo.

Watch it write

Code appears as the model writes it, with its real speed beside it. Press Stop the moment it goes the wrong way.

Keep or undo each block

Every edit lands as a diff. Take the good parts of a change and throw out the rest, or undo every file from a step with one click.

It checks its own work

After each edit, your project's TypeScript runs. Anvil adds missing imports itself and sends other errors back to the model to fix.

You stay in charge

Nothing runs in your shell until you approve it. A model that repeats itself gets stopped and told why, so it can't loop forever.

What it can't do yet

All questions Documentation

Does it replace VS Code?

For many people working in TypeScript, Angular or Python, it can cover the daily work. VS Code is far more mature, so if you depend on specific extensions, keep it.

Do VS Code extensions run?

Themes and snippets do. Extensions that are programs don't, because they're written for VS Code's internal engine.

Can a local model build a whole project by itself?

Not reliably. Small models are good at single files and small features while you review the work. For a whole project, use a bigger model through an API key.

How well tested is it?

The test suite runs on Mac, Windows and Linux machines. It's a new project, though, and the Anthropic and OpenAI connections haven't been tried with real keys yet. Please report what you find.
