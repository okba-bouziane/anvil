An editor first. AI only if you want it.

Install it and start coding, with no account, no model and no key. Press one shortcut and the agent is gone.

No AI

Nothing to set up
  • Errors underlined as you type
  • Completion, go to definition and rename across files
  • Terminal, Git, project search and replace

On your computer

Your code stays with you
  • MLX on Macs with Apple Silicon
  • Ollama or LM Studio on any system
  • Works on a plane, in a basement, or at a client who bans the cloud

Your API key

For the bigger jobs
  • Anthropic, OpenAI or any OpenAI-style server
  • Keys stay in your system's secure storage
  • The app always says when code leaves your computer

Built for models that make mistakes

A small model on a laptop gets things wrong. Anvil assumes that, and makes every mistake cheap.

Keep or undo every block

Each edit lands as a diff. Accept the good parts of a change and throw out the rest.

Undo a whole step

One click puts back every file the model touched, even the changes you already kept.

TypeScript checks its work

Anvil adds missing imports itself, then sends the other errors back to the model to fix.

It stops when it's stuck

A model repeating itself gets stopped and told why, so it can't loop forever.

Commands ask first

Nothing runs in your shell until you approve it, unless you choose otherwise.

The task: add a task priority field across an existing NestJS and Angular project, with no file list or plan. The model changed 11 files and wrote 3 of those tests. The backend passed its type check and the frontend built, though we didn't try the feature in a browser, and earlier versions of this test failed. A small local model is good for single files, small features and tests while you review the work. For a whole project, use a bigger model through an API key.

What's in the box

Editing

  • Tabs, and edits that survive switching
  • Auto-save and format on save
  • Light, dark and system themes
  • Create, rename, delete, open by name

TypeScript and JavaScript

  • Live errors and a Problems panel
  • Completion with automatic imports
  • Hover, definitions, references
  • Rename across files

Project tools

  • Built-in terminal with tabs
  • Git: stage, commit, compare, pull, push
  • Search and replace across the project
  • Run npm scripts with one click

Agent

  • Agent, Plan and Ask modes
  • Code appears as it's written
  • Grey suggestions from a local model
  • Settings, snippets and themes from VS Code

What it can't do yet

Anvil is young, and VS Code is far more complete. Better you read this here than find out later.

VS Code extensions don't run. You can import settings, snippets and color themes, but not extensions like ESLint.
No debugger yet. Debug in the terminal or another tool for now.
Code help is TypeScript and JavaScript only. Other languages get syntax colors.
Windows and Linux are new. So far they've passed automated tests only, so please report problems.
Cloud providers are lightly tested. The Anthropic and OpenAI connections haven't been tried with real keys yet.
Approved commands run as you. They can change anything your user can, and can't be undone from Anvil.
