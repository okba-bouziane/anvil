Every edit lands as a diff. Take the good parts of a change and throw out the rest, or undo every file from a step with one click.

After each edit, your project's TypeScript runs. Anvil adds missing imports itself and sends other errors back to the model to fix.

    Straight answers
    
What it can't do yet

  

  

    
Does it replace VS Code?
Not for everyone yet. VS Code is far more complete. Anvil covers everyday TypeScript and JavaScript work, and its agent works offline. It has no debugger yet.

    
Do VS Code extensions run?
No. Extensions like ESLint need VS Code's own engine underneath. One button imports your settings, snippets and color themes, and tells you which extensions it couldn't bring.

    
What about other languages, like Python?
Other languages get syntax colors, and HTML, CSS and JSON get some completion. Errors, go to definition and rename are for TypeScript and JavaScript only so far.

    
Can a local model build a whole project by itself?
Not reliably. Small models are good at single files and small features while you review the work. For a whole project, use a bigger model through an API key.

    
Is it safe to let the model run commands?
Commands ask first by default. Once you approve one, it runs with your full user permissions, and Anvil can't undo what it changes. Leave Auto-run off unless you trust the project.

    
How well tested is it?
The test suite runs on Mac, Windows and Linux machines. It's a new project, though: Windows and Linux haven't been used on real desktops much yet, and the Anthropic and OpenAI connections haven't been tried with real keys. Please report what you find.
