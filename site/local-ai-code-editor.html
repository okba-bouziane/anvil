A code editor with a local AI agent

Pitoo can run its agent on a model on your own computer, so your code stays there. It's built around what small models get wrong.

How it copes with small models

  • Every edit can be reviewed: Keep or undo each block, file or whole step.
  • Missing imports get fixed: after an edit, your project's TypeScript adds them and sends other errors back to the model.
  • Loops get caught: repeated calls are stopped instead of running forever.
  • Long chats get trimmed: in a way that keeps waits short.

What to expect

On a MacBook with an M1 Pro and 16 GB of memory, a 6 GB model wrote about 24 tokens per second in one test, and took about 10 minutes to add a feature across 11 files. Earlier versions of that test failed, so review the work. Small models suit single files and small features better than whole projects.

Setup

On a Mac with Apple Silicon, Settings guides you through MLX. On any system, you can point Pitoo at Ollama or LM Studio. If you'd rather use a bigger model, Anthropic and OpenAI work with your own API key.
